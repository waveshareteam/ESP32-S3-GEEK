# Mount a microSD card

**English** | [简体中文](README_ZH.md)

## What It Does

Mounts a microSD card using software SPI.

## Hardware Required

ESP32-S3-GEEK development board. A microSD card with a supported filesystem.

## How to Run

Copy `sdcard.py` and `boot.py` to the board, insert the card and restart.

## Expected Result

MicroPython mounts the card at `/sd`.
