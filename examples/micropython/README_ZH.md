# ESP32-S3-GEEK MicroPython 示例

[English](README.md) | **简体中文**

按[固件烧录指南](https://docs.waveshare.net/ESP32-S3-GEEK/Firmware-Flashing/)安装官方 MicroPython 固件，再用 Thonny 打开示例。LCD 示例需要同目录下的 BMP 和 `bmp_reader.py`，SD 示例需要 `sdcard.py`。

| 示例 | 主要功能 |
| --- | --- |
| [BLE](BLE/WS_Bluetooth.py) | BLE 外设 |
| [LCD](LCD/lcd_example.py) | 显示 BMP |
| [SD](SD/boot.py) | 挂载并使用 microSD |
| [UART](UART/Uart0.py) | 串行通信 |
| [WIFI](WIFI/) | 热点和客户端模式 |
