# Serial communication

**English** | [简体中文](README_ZH.md)

## What It Does

Demonstrates serial communication through MicroPython.

## Hardware Required

ESP32-S3-GEEK development board. Connect a 3.3 V USB-to-UART adapter to GPIO43 (TX), GPIO44 (RX) and GND. Set the host terminal to 115200 baud.

## How to Run

Run `Uart0.py` from Thonny.

## Expected Result

The program reads and writes serial data.
