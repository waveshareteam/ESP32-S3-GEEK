# ESP32-S3-GEEK MicroPython Examples

**English** | [简体中文](README_ZH.md)

Install the official MicroPython firmware using the [flashing guide](https://docs.waveshare.com/ESP32-S3-GEEK/Firmware-Flashing/), then open an example in Thonny. The LCD demo also needs the bundled BMP and `bmp_reader.py`. The SD demo needs `sdcard.py`.

| Example | Main feature |
| --- | --- |
| [BLE](BLE/WS_Bluetooth.py) | BLE peripheral |
| [LCD](LCD/lcd_example.py) | Display a BMP |
| [SD](SD/boot.py) | Mount and use microSD |
| [UART](UART/Uart0.py) | Serial communication |
| [WIFI](WIFI/) | Access point and station modes |
