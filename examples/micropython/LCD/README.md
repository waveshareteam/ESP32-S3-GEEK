# Display a BMP

**English** | [简体中文](README_ZH.md)

## What It Does

Displays a bundled BMP on the onboard LCD.

## Hardware Required

ESP32-S3-GEEK development board.

## How to Run

Copy `ESP32-S3-GEEK.bmp` and `bmp_reader.py` to the device, then run `lcd_example.py` from the same directory.

## Expected Result

The LCD displays the image.

## Troubleshooting

None yet.
