# Wi-Fi access point and station

**English** | [简体中文](README_ZH.md)

## What It Does

Provides separate access point and station scripts.

## Hardware Required

ESP32-S3-GEEK development board. A Wi-Fi client or 2.4 GHz access point, depending on the mode.

## How to Run

Run `WIFI_AP.py` for access point mode or configure your Wi-Fi settings and run `WIFI_STA.py` for station mode.

## Expected Result

The board advertises an access point or connects to the configured network.

## Troubleshooting

None yet.
