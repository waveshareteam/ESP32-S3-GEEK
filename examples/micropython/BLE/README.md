# BLE peripheral

**English** | [简体中文](README_ZH.md)

## What It Does

Creates a BLE peripheral for exchanging data with a GATT client.

## Hardware Required

ESP32-S3-GEEK development board. A BLE-capable phone or computer.

## How to Run

Run `WS_Bluetooth.py` in Thonny.

## Expected Result

The peripheral becomes discoverable over BLE.

None yet.
