# MQTT 发布和订阅

[English](README.md) | **简体中文**

## 功能

演示MQTT 发布和订阅。

## 硬件需求

ESP32-S3-GEEK 开发板。

## 怎么运行

将 Arduino IDE 的项目文件夹位置设为 [Arduino 示例目录](../../)，按[首页](../../../../README_ZH.md)安装开发板包并设置开发板。打开 [16_MQTT_sub_pub.ino](16_MQTT_sub_pub.ino) 后上传。

## 预期现象

草图发布消息并处理订阅回调。

## 常见问题

配置自己的 Wi-Fi 和测试用 MQTT 代理。
