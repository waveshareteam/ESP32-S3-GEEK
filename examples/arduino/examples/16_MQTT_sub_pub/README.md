# MQTT publish and subscribe

**English** | [简体中文](README_ZH.md)

## What It Does

Demonstrates mQTT publish and subscribe.

## Hardware Required

ESP32-S3-GEEK development board.

## How to Run

Set the Arduino IDE sketchbook to the [Arduino directory](../../) and follow the [development environment instructions](../../../../README.md) for the board package and settings. Open [16_MQTT_sub_pub.ino](16_MQTT_sub_pub.ino) and upload it.

## Expected Result

The sketch publishes messages and handles subscription callbacks.

## Troubleshooting

Use your own Wi-Fi and test broker settings.
