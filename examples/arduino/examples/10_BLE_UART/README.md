# BLE serial bridge

**English** | [简体中文](README_ZH.md)

## What It Does

Demonstrates bLE serial bridge.

## Hardware Required

ESP32-S3-GEEK development board. Use a BLE GATT client that supports characteristic writes and notifications.

## How to Run

Set the Arduino IDE sketchbook to the [Arduino directory](../../) and follow the [development environment instructions](../../../../README.md) for the board package and settings. Open [10_BLE_UART.ino](10_BLE_UART.ino) and upload it.

## Expected Result

Data moves between the BLE client and the serial monitor.
