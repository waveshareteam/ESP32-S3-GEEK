# BLE 串口通信

[English](README.md) | **简体中文**

## 功能

演示BLE 串口通信。

## 硬件需求

ESP32-S3-GEEK 开发板。 使用支持特征写入和通知的 BLE GATT 客户端。

## 怎么运行

将 Arduino IDE 的项目文件夹位置设为 [Arduino 示例目录](../../)，按[首页](../../../../README_ZH.md)安装开发板包并设置开发板。打开 [10_BLE_UART.ino](10_BLE_UART.ino) 后上传。

## 预期现象

数据在 BLE 客户端与串口监视器之间收发。
