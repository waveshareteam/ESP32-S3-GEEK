# LCD 显示 BLE 数据

[English](README.md) | **简体中文**

## 功能

演示LCD 显示 BLE 数据。

## 硬件需求

ESP32-S3-GEEK 开发板。 在手机或电脑上使用 BLE GATT 客户端。

## 怎么运行

将 Arduino IDE 的项目文件夹位置设为 [Arduino 示例目录](../../)，按[首页](../../../../README_ZH.md)安装开发板包并设置开发板。打开 [09_BLE_LCD.ino](09_BLE_LCD.ino) 后上传。

## 预期现象

LCD 显示已连接 BLE 客户端发送的数据。
