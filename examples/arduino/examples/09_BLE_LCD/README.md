# BLE data on the LCD

**English** | [简体中文](README_ZH.md)

## What It Does

Demonstrates bLE data on the LCD.

## Hardware Required

ESP32-S3-GEEK development board. Use a BLE GATT client on a phone or computer.

## How to Run

Set the Arduino IDE sketchbook to the [Arduino directory](../../) and follow the [development environment instructions](../../../../README.md) for the board package and settings. Open [09_BLE_LCD.ino](09_BLE_LCD.ino) and upload it.

## Expected Result

The LCD shows data received from the connected BLE client.
