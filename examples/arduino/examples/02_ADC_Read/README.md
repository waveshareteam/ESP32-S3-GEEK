# ADC sampling

**English** | [简体中文](README_ZH.md)

## What It Does

Demonstrates aDC sampling.

## Hardware Required

ESP32-S3-GEEK development board. Apply a voltage within the board’s ADC input limits.

## How to Run

Set the Arduino IDE sketchbook to the [Arduino directory](../../) and follow the [development environment instructions](../../../../README.md) for the board package and settings. Open [02_ADC_Read.ino](02_ADC_Read.ino) and upload it.

## Expected Result

The serial monitor prints the raw reading and voltage in millivolts.
