# Wi-Fi TCP 客户端

[English](README.md) | **简体中文**

## 功能

演示Wi-Fi TCP 客户端。

## 硬件需求

ESP32-S3-GEEK 开发板。

## 怎么运行

将 Arduino IDE 的项目文件夹位置设为 [Arduino 示例目录](../../)，按[首页](../../../../README_ZH.md)安装开发板包并设置开发板。打开 [13_WIFI_TCP_Client.ino](13_WIFI_TCP_Client.ino) 后上传。

## 预期现象

开发板连接指定 TCP 服务端并报告数据收发情况。

## 常见问题

上传前设置 Wi-Fi 和 TCP 服务端地址与端口。
