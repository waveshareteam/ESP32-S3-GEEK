# Wi-Fi TCP client

**English** | [简体中文](README_ZH.md)

## What It Does

Demonstrates wi-Fi TCP client.

## Hardware Required

ESP32-S3-GEEK development board.

## How to Run

Set the Arduino IDE sketchbook to the [Arduino directory](../../) and follow the [development environment instructions](../../../../README.md) for the board package and settings. Open [13_WIFI_TCP_Client.ino](13_WIFI_TCP_Client.ino) and upload it.

## Expected Result

The board connects to the configured TCP server and reports data exchange.

## Troubleshooting

Configure Wi-Fi and the TCP server address and port before uploading.
