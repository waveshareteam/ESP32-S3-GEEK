# LCD image and backlight control

**English** | [简体中文](README_ZH.md)

## What It Does

Demonstrates lCD image and backlight control.

## Hardware Required

ESP32-S3-GEEK development board.

## How to Run

Set the Arduino IDE sketchbook to the [Arduino directory](../../) and follow the [development environment instructions](../../../../README.md) for the board package and settings. Open [05_LCD_Button.ino](05_LCD_Button.ino) and upload it.

## Expected Result

Button presses change the displayed image or backlight state.

None yet.
