# BLE keyboard

**English** | [简体中文](README_ZH.md)

## What It Does

Demonstrates bLE keyboard.

## Hardware Required

ESP32-S3-GEEK development board. Use a Bluetooth host dedicated to the demo.

## How to Run

Set the Arduino IDE sketchbook to the [Arduino directory](../../) and follow the [development environment instructions](../../../../README.md) for the board package and settings. Open [11_BLE_Keyboard.ino](11_BLE_Keyboard.ino) and upload it.

## Expected Result

A paired host receives keyboard events from the board.
