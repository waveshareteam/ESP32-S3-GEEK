# BLE 键盘

[English](README.md) | **简体中文**

## 功能

演示BLE 键盘。

## 硬件需求

ESP32-S3-GEEK 开发板。 使用专门用于演示的蓝牙主机。

## 怎么运行

将 Arduino IDE 的项目文件夹位置设为 [Arduino 示例目录](../../)，按[首页](../../../../README_ZH.md)安装开发板包并设置开发板。打开 [11_BLE_Keyboard.ino](11_BLE_Keyboard.ino) 后上传。

## 预期现象

已配对的主机会收到开发板发送的键盘事件。
