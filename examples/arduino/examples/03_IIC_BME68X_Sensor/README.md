# BME68x over I²C

**English** | [简体中文](README_ZH.md)

## What It Does

Demonstrates bME68x over I²C.

## Hardware Required

ESP32-S3-GEEK development board. Connect an external BME68x sensor over I²C.

## How to Run

Set the Arduino IDE sketchbook to the [Arduino directory](../../) and follow the [development environment instructions](../../../../README.md) for the board package and settings. Open [03_IIC_BME68X_Sensor.ino](03_IIC_BME68X_Sensor.ino) and upload it.

## Expected Result

The serial monitor prints readings from the sensor.
