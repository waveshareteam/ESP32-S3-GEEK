# I²C 读取 BME68x

[English](README.md) | **简体中文**

## 功能

演示I²C 读取 BME68x。

## 硬件需求

ESP32-S3-GEEK 开发板。 通过 I²C 接入外置 BME68x 传感器。

## 怎么运行

将 Arduino IDE 的项目文件夹位置设为 [Arduino 示例目录](../../)，按[首页](../../../../README_ZH.md)安装开发板包并设置开发板。打开 [03_IIC_BME68X_Sensor.ino](03_IIC_BME68X_Sensor.ino) 后上传。

## 预期现象

串口监视器输出传感器测量值。
