# microSD filesystem operations

**English** | [简体中文](README_ZH.md)

## What It Does

Demonstrates microSD filesystem operations.

## Hardware Required

ESP32-S3-GEEK development board. Insert a writable microSD card. Use a card reserved for testing because the sketch modifies files.

## How to Run

Set the Arduino IDE sketchbook to the [Arduino directory](../../) and follow the [development environment instructions](../../../../README.md) for the board package and settings. Open [07_SD_Test.ino](07_SD_Test.ino) and upload it.

## Expected Result

The serial monitor reports file operations and read/write timing.
