# microSD 文件操作

[English](README.md) | **简体中文**

## 功能

演示microSD 文件操作。

## 硬件需求

ESP32-S3-GEEK 开发板。 插入可写的测试用 microSD 卡，示例会修改卡上的文件。

## 怎么运行

将 Arduino IDE 的项目文件夹位置设为 [Arduino 示例目录](../../)，按[首页](../../../../README_ZH.md)安装开发板包并设置开发板。打开 [07_SD_Test.ino](07_SD_Test.ino) 后上传。

## 预期现象

串口监视器显示文件操作结果和读写耗时。
