# Serial echo

**English** | [简体中文](README_ZH.md)

## What It Does

Demonstrates serial echo.

## Hardware Required

ESP32-S3-GEEK development board.

## How to Run

Set the Arduino IDE sketchbook to the [Arduino directory](../../) and follow the [development environment instructions](../../../../README.md) for the board package and settings. Open [04_UART0.ino](04_UART0.ino) and upload it.

## Expected Result

Text followed by a newline is echoed to the serial monitor.

## Troubleshooting

Use short lines terminated by a newline.
