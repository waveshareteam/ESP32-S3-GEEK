# Network time on the LCD

**English** | [简体中文](README_ZH.md)

## What It Does

Demonstrates network time on the LCD.

## Hardware Required

ESP32-S3-GEEK development board.

## How to Run

Set the Arduino IDE sketchbook to the [Arduino directory](../../) and follow the [development environment instructions](../../../../README.md) for the board package and settings. Open [06_LCD_Time.ino](06_LCD_Time.ino) and upload it.

## Expected Result

The LCD shows the date and time after network synchronization.

## Troubleshooting

Set your Wi-Fi credentials in the sketch before uploading.
