# Wi-Fi access point on the LCD

**English** | [简体中文](README_ZH.md)

## What It Does

Demonstrates wi-Fi access point on the LCD.

## Hardware Required

ESP32-S3-GEEK development board. Use a Wi-Fi client to connect to the board’s access point.

## How to Run

Set the Arduino IDE sketchbook to the [Arduino directory](../../) and follow the [development environment instructions](../../../../README.md) for the board package and settings. Open [12_WIFI_AP_LCD.ino](12_WIFI_AP_LCD.ino) and upload it.

## Expected Result

The LCD displays the access point information.
