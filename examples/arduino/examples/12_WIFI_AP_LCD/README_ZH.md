# LCD 显示 Wi-Fi 热点

[English](README.md) | **简体中文**

## 功能

演示LCD 显示 Wi-Fi 热点。

## 硬件需求

ESP32-S3-GEEK 开发板。 使用 Wi-Fi 客户端连接开发板热点。

## 怎么运行

将 Arduino IDE 的项目文件夹位置设为 [Arduino 示例目录](../../)，按[首页](../../../../README_ZH.md)安装开发板包并设置开发板。打开 [12_WIFI_AP_LCD.ino](12_WIFI_AP_LCD.ino) 后上传。

## 预期现象

LCD 显示热点信息。
