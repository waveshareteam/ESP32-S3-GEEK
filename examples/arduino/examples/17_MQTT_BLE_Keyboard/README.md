# MQTT and BLE keyboard integration

**English** | [简体中文](README_ZH.md)

## What It Does

Demonstrates mQTT and BLE keyboard integration.

## Hardware Required

ESP32-S3-GEEK development board. Use your own test broker and a dedicated Bluetooth host.

## How to Run

Set the Arduino IDE sketchbook to the [Arduino directory](../../) and follow the [development environment instructions](../../../../README.md) for the board package and settings. Open [17_MQTT_BLE_Keyboard.ino](17_MQTT_BLE_Keyboard.ino) and upload it.

## Expected Result

The board connects to MQTT and presents itself as a BLE keyboard.
