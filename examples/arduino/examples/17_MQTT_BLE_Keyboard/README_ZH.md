# MQTT 与 BLE 键盘联动

[English](README.md) | **简体中文**

## 功能

演示MQTT 与 BLE 键盘联动。

## 硬件需求

ESP32-S3-GEEK 开发板。 使用自己的测试用 MQTT 代理和专门的蓝牙测试主机。

## 怎么运行

将 Arduino IDE 的项目文件夹位置设为 [Arduino 示例目录](../../)，按[首页](../../../../README_ZH.md)安装开发板包并设置开发板。打开 [17_MQTT_BLE_Keyboard.ino](17_MQTT_BLE_Keyboard.ino) 后上传。

## 预期现象

开发板连接 MQTT，并作为 BLE 键盘广播。
