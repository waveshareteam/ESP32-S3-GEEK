# Wi-Fi 网页服务器

[English](README.md) | **简体中文**

## 功能

演示Wi-Fi 网页服务器。

## 硬件需求

ESP32-S3-GEEK 开发板。

## 怎么运行

将 Arduino IDE 的项目文件夹位置设为 [Arduino 示例目录](../../)，按[首页](../../../../README_ZH.md)安装开发板包并设置开发板。打开 [15_WIFI_Web_Server.ino](15_WIFI_Web_Server.ino) 后上传。

## 预期现象

开发板在局域网内提供 HTTP 页面。

## 常见问题

上传前填写 Wi-Fi 凭据。
