# Wi-Fi web server

**English** | [简体中文](README_ZH.md)

## What It Does

Demonstrates wi-Fi web server.

## Hardware Required

ESP32-S3-GEEK development board.

## How to Run

Set the Arduino IDE sketchbook to the [Arduino directory](../../) and follow the [development environment instructions](../../../../README.md) for the board package and settings. Open [15_WIFI_Web_Server.ino](15_WIFI_Web_Server.ino) and upload it.

## Expected Result

The board serves a page over HTTP on the local network.

## Troubleshooting

Set the Wi-Fi credentials before uploading.
