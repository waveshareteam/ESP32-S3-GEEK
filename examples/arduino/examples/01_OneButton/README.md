# Button gestures

**English** | [简体中文](README_ZH.md)

## What It Does

Demonstrates button gestures.

## Hardware Required

ESP32-S3-GEEK development board.

## How to Run

Set the Arduino IDE sketchbook to the [Arduino directory](../../) and follow the [development environment instructions](../../../../README.md) for the board package and settings. Open [01_OneButton.ino](01_OneButton.ino) and upload it.

## Expected Result

The LCD labels single, double and long presses.
