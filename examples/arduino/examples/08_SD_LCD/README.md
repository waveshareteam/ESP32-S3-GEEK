# JPEG display from microSD

**English** | [简体中文](README_ZH.md)

## What It Does

Demonstrates jPEG display from microSD.

## Hardware Required

ESP32-S3-GEEK development board. Insert a microSD card and copy the numbered JPEGs from [pic](pic/) to its root.

## How to Run

Set the Arduino IDE sketchbook to the [Arduino directory](../../) and follow the [development environment instructions](../../../../README.md) for the board package and settings. Open [08_SD_LCD.ino](08_SD_LCD.ino) and upload it.

## Expected Result

The LCD cycles through the numbered JPEG files on the microSD card.
