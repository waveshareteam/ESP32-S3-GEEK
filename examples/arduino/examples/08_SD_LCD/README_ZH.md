# 显示 microSD 中的 JPEG

[English](README.md) | **简体中文**

## 功能

演示显示 microSD 中的 JPEG。

## 硬件需求

ESP32-S3-GEEK 开发板。 插入 microSD 卡，并将 [pic](pic/) 中的 `1.jpg` 到 `8.jpg` 复制到卡根目录。

## 怎么运行

将 Arduino IDE 的项目文件夹位置设为 [Arduino 示例目录](../../)，按[首页](../../../../README_ZH.md)安装开发板包并设置开发板。打开 [08_SD_LCD.ino](08_SD_LCD.ino) 后上传。

## 预期现象

LCD 轮播 microSD 卡上的编号 JPEG 图片。

## 常见问题

暂无。
