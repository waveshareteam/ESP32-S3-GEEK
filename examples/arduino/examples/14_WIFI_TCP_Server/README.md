# Wi-Fi TCP server

**English** | [简体中文](README_ZH.md)

## What It Does

Demonstrates wi-Fi TCP server.

## Hardware Required

ESP32-S3-GEEK development board. Configure Wi-Fi and use a TCP client on the same network.

## How to Run

Set the Arduino IDE sketchbook to the [Arduino directory](../../) and follow the [development environment instructions](../../../../README.md) for the board package and settings. Open [14_WIFI_TCP_Server.ino](14_WIFI_TCP_Server.ino) and upload it.

## Expected Result

The board accepts TCP connections and reports incoming data.
