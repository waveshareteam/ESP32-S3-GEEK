# Wi-Fi TCP 服务端

[English](README.md) | **简体中文**

## 功能

演示Wi-Fi TCP 服务端。

## 硬件需求

ESP32-S3-GEEK 开发板。 配置 Wi-Fi，并使用同一网络内的 TCP 客户端。

## 怎么运行

将 Arduino IDE 的项目文件夹位置设为 [Arduino 示例目录](../../)，按[首页](../../../../README_ZH.md)安装开发板包并设置开发板。打开 [14_WIFI_TCP_Server.ino](14_WIFI_TCP_Server.ino) 后上传。

## 预期现象

开发板接受 TCP 连接并报告收到的数据。
